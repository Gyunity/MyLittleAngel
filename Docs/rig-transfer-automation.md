# 뼈대 이식 자동화 검토 (2026.11.17)

## 목표
기준 모델(SampleDog)의 뼈대·웨이트를 새로 생성한 모델에 옮기는 과정을
사람 손 없이 Blender 스크립트로 돌릴 수 있는지 확인

## 단계별 검토

| 단계 | 수작업 (11/16) | 자동화 | 방법 |
| --- | --- | --- | --- |
| 1. 불러오기 | 파일 > 가져오기 > glTF | 쉬움 | `bpy.ops.import_scene.gltf` |
| 2. 크기·위치 맞추기 | 눈으로 S, G 조정 | 어려움 | 아래 참고 |
| 3. 뼈대 연결 | Ctrl+P > 빈 그룹과 함께 | 쉬움 | `parent_set(type='ARMATURE_NAME')` |
| 4. 웨이트 전송 | 가장 가까운 면 보간, 소스 모든 레이어, 대상 이름으로 | 쉬움 | `data_transfer` + `vertex_group_normalize_all` |
| 5. 내보내기 | glTF 바이너리 | 쉬움 | `bpy.ops.export_scene.gltf(export_format='GLB')` |

- 화면 없이 실행 가능: `blender -b -P script.py`
- 서버에서 처리 가능, 리깅 API 불필요 → 모델당 35크레딧 (생성 30 + 리메시 5)

## 크기·위치 맞추기 시험

수작업으로 맞춘 결과 위에 두 모델의 경계 상자를 겹쳐 비교

- 메시는 잘 겹치는데 경계 상자는 어긋남
- 원인: 경계 상자는 가장 바깥 점 하나로 정해져서 털 끝·떨어진 조각에 영향을 받음
- 결론: 단순 경계 상자 방식은 부족

## 대안
1. 정점 위치의 2~98% 범위로 상자를 계산해 튀어나온 점 제외
2. 표면 정합(ICP)으로 크기·위치 미세 조정

## 남은 문제
- 같은 푸들 모델끼리만 시험함 → 다른 견종 모델로 시험 필요
