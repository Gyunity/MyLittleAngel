## 전체 흐름

```
강아지 사진
  → 표준 자세·멀티뷰(정면·측면·후면) 참조 이미지
  → Meshy 3D 생성 (meshy-7.1, PBR, 2K 텍스처)
  → Remesh API (quad, 15,000면)
  → Blender에서 기준 모델의 뼈대·웨이트 이식
  → GLB
  → Unity 런타임 로딩 → AR 화면에서 걷기
```

## 주요 구현

### 런타임 GLB 로딩
- glTFast로 `persistentDataPath`의 GLB를 실행 중에 불러옴
- 안드로이드에서는 `StreamingAssets`를 일반 파일 경로로 읽을 수 없어 `UnityWebRequest`로 복사 후 로딩
- 런타임에 불러온 애니메이션은 Animator에 바로 붙일 수 없어 Legacy Animation으로 재생
- 모델 키를 렌더러 Bounds로 재서 목표 크기에 맞게 자동 조정하고 바닥에 맞춰 배치

### AR
- AR Foundation + ARCore로 실기기 카메라 화면 표시

## 결정과 근거

같은 조건으로 나란히 비교한 뒤 결정했습니다.

### 생성 서비스: Tripo vs Meshy
- Tripo: 다리가 붙고 다리 뼈가 꼬리 쪽으로 연결됨
- Meshy: 사족보행 리깅 지원, 멀티뷰 생성으로 좌우 대칭 확보 → **Meshy로 결정**

### 리메시 방식

| 방식 | 크레딧 | 결과 |
| --- | --- | --- |
| 생성 중 리메시 + N1 텍스처 | 30 | 털이 각진 조각처럼 보임 |
| 생성 중 리메시 + PBR | 30 | 돌기가 빽빽하게 보임 |
| 생성 후 리메시 triangle 15k | 30+5 | 여전히 각짐 |
| 리메시 triangle 30k | 5 | 조각은 작아졌지만 각짐 |
| **리메시 quad 15k** | 5 | **가장 자연스러움, 정점 수 최소** |

- 노멀 맵 세기를 낮춰도 각진 형태가 남음 → 원인은 텍스처가 아니라 리메시 방식
- 생성 1회: 약 2분, 35크레딧 (생성 30 + quad 리메시 5)

### 리깅: API 자동 리깅 vs 기준 모델 뼈대 이식

| 시도 | 결과 |
| --- | --- |
| API 기본값 | 두 발(biped) 뼈대로 리깅, 앞다리가 팔처럼 움직이고 머리가 찌그러짐 |
| API `animation_type: quadruped` | 네 발 뼈대는 정상, 걸을 때 몸 가운데가 V자로 접힘 |
| 기준 모델 뼈대·웨이트 이식 | **관절이 접히지 않고 걷기 성공** |

- 리깅 API의 `animation_type` 기본값은 biped. 공식 문서 본문에는 없고 openapi 정의 파일에만 있음
- API는 관절 위치를 자동 추정하고 마커를 직접 지정하는 옵션이 없어, 털이 풍성한 푸들은 엉덩이 관절이 배 근처로 잡힘
- 그래서 웹에서 마커를 직접 찍어 리깅한 모델을 기준 모델로 두고, 새 모델에 뼈대와 웨이트를 옮기는 방식으로 결정

## 뼈대 이식 방법 (Blender)

1. 기준 모델(휴식 위치)과 새 모델을 불러와 크기·위치를 겹치게 맞추고 모든 변환 적용
2. 새 모델을 뼈대에 연결: Ctrl+P > 빈 그룹과 함께
3. 웨이트 전송: 가장 가까운 면 보간, 소스 모든 레이어, 대상 이름으로 → 모두 정규화
4. 새 모델과 뼈대만 선택해 GLB로 내보내기

자동화 검토 결과는 [Docs/rig-transfer-automation.md](Docs/rig-transfer-automation.md)에 정리했습니다.

## 트러블슈팅

| 문제 | 원인 | 해결 |
| --- | --- | --- |
| 실기기에서 모델이 핑크색 | 빌드 시 glTFast 셰이더 제외 | Graphics 설정에서 셰이더를 기록해 Preload Shaders에 등록 |
| AR 카메라 검은 화면, "texture buffer handle is null" | URP에 AR 배경 렌더링 누락, Vulkan | AR Background Renderer Feature 추가, Graphics API를 OpenGLES3로 고정 |
| 앞다리 두 개가 붙어서 움직임 | 앉아서 다리를 모은 원본 사진 | 서 있는 표준 자세 참조 이미지로 교체 |
| 뒷다리가 위로 접힘 | 사진 한 장으로는 안 보이는 쪽 다리를 AI가 추측해 좌우 비대칭 | 정면·측면·후면 멀티뷰로 생성 |
| 리깅 클립 이름이 하나뿐 (`Armature\|Unreal Take\|baselayer`) | Meshy 리깅 결과 형식 | 첫 번째 클립을 찾아 반복 재생 |
| 스크립트 한글 출력 깨짐 | 파일이 ANSI로 저장됨 | UTF-8로 다시 저장 |

## 알려진 문제

- 정수리·귀 위쪽 폴리곤이 거침
- 애니메이션이 클립별 파일로 나뉨 → 여러 모션을 합치는 방법 필요
